# bahadirdogru.com

Bahadır Doğru’nun kişisel sitesi. [Academic Pages](https://github.com/academicpages/academicpages.github.io) temasıyla üretilir ve [bahadirdogru.com](https://bahadirdogru.com) adresinde yayımlanır.

- `/` hakkında
- `/calismalar/` açık kaynak çalışmalar
- `/notlar/` NetOpenX örnekleri
- `/arsiv/` 2014–2022 blog yazıları

```bash
bundle install
bundle exec jekyll serve
```
